# Simple Calculator ➗✖️➕

A basic calculator app built with **C# and .NET**.  
It performs simple arithmetic operations and demonstrates **UI programming + OOP principles**.

## ✨ Features
- Addition, subtraction, multiplication, division
- Clear/reset functionality
- Error handling for invalid inputs (e.g., divide by zero)

## 🛠 Tech Stack
- **Language**: C#
- **Framework**: .NET (WinForms/WPF)
